## Princípios
1. **Brasil e mercado ocidental como padrão**: português brasileiro, alfabeto latino, cultura visual e regras comerciais do mercado local. Referências globais podem inspirar, sem replicar conteúdo fora de contexto.
2. **Estratégia antes de estética**: peça deve vender, construir marca, informar ou engajar com objetivo definido.
3. **Marca e produto fiéis**: nunca inventar características técnicas, versões de carros, logotipos, preços, taxas, descontos ou aval de fabricantes.
4. **Inspiração sem cópia**: referenciar fontes, respeitar copyright/licenças e verificar direitos de uso.
5. **Controle humano**: revisar ortografia, posicionamento, hierarquia, cores, detalhes do produto e especificação técnica de arquivos.
6. **Repositório público**: não incluir dados confidenciais de clientes.

**Estado:** primeira versão de conhecimento e processos. Referências externas são links; não estão automaticamente instaladas no Mac ou no ChatGPT. GitHub não treina o modelo permanentemente; o ChatGPT precisa consultar os arquivos.
